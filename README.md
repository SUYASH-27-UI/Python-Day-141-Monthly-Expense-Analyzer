# Python Day 141 - Monthly Expense Analyzer

## About
A Python project that reads expense records from a CSV file and generates monthly spending reports.

## Features
- Read expense data from `expenses.csv`
- Filter expenses by month
- Calculate category-wise spending
- Calculate total and average expenses
- Count transactions
- Handle invalid CSV records

## Technologies
- Python
- CSV file handling
- `datetime`
- `collections`

## Files
- `expense_analyzer.py` - Main program
- `expenses.csv` - Sample expense records

## How to Run
1. Keep `expense_analyzer.py` and `expenses.csv` in the same working directory.
2. Run:

   `python expense_analyzer.py`

3. Select View Monthly Report.
4. Enter a month such as `2026-10`.

## Learning Outcomes
Practiced CSV processing, functions, dictionaries, list comprehensions, date filtering, exception handling, and data analysis.
